# Estúdio de Criativos

Ferramentas de criativo para quem roda tráfego pago. Processo 100% no navegador.

## Rodar
```bash
npm install
cp .env.example .env   # coloque sua chave Pix (p/ ativar a aba Pro completa)
npm run dev            # http://localhost:5199
```

## Build de produção
```bash
npm run build          # gera dist/ → subir em qualquer hosting estático free
npm run preview        # testa o build em http://localhost:5199
```

## Ferramentas
1. **Redimensionar** — 9:16 · 4:5 · 1:1 · 16:9 nos tamanhos exatos de anúncio
2. **Legenda & marca d'água** — texto em 6 posições c/ faixa · marca tilé diagonal
3. **Print → Texto** — OCR PT+EN no aparelho (grátis: 5/dia)
4. **Fontes p/ Copy** — 18 estilos Unicode (grátis ilimitado)
5. **Pro** — R$ 29,90/30 dias via Pix copia-e-cola, sem recorrência
